# Changelog

All notable changes to PlexKillstreaks are documented here.

## 1.0.0

- Added current and highest killstreak tracking.
- Added configurable milestone announcements.
- Added configurable sounds and action-bar feedback.
- Added streak progress and next-milestone support.
- Added SQLite persistence with asynchronous database handling.
- Added optional PlaceholderAPI integration.
- Added `/streak`, `/streaks`, and `/streakreload`.
- Added configurable messages and plugin behavior.
