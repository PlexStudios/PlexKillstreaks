# PlexKillstreaks Support

## Bug Reports

Use the repository bug report template and include:

- PlexKillstreaks version
- Minecraft version
- Paper version
- Relevant plugins
- Steps to reproduce
- Relevant console output

## Feature Requests

Use the feature request template and describe the problem the feature would solve.

## Before Reporting

Confirm that the issue can still be reproduced on the current plugin version and is not caused by an unrelated server configuration or plugin conflict.

## Security

Do not publish passwords, tokens, database credentials, private configuration values, or other secrets in public issues.
